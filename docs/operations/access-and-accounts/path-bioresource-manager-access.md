# Path BioResource Manager Access

!!! abstract "What this page tells you"
    Get manager access to the Path BioResource (CAMRIS) website so you can add or remove users without contacting Rachel DeAngelis each time; email Rachel with Kate cc'ed to request it. Links the assignment page.

*   You can add/remove people without needing to contact Rachel DeAngelis/get Kate's approval each time, you can obtain manager access to the Path BioResource website
    *   You will need to email Rachel DeAngelis with Kate cc'ed to obtain approval

**Path BioResource Website-** [https://pathbio.med.upenn.edu/pbr/secure/assign.php](https://pathbio.med.upenn.edu/pbr/secure/assign.php)
