# Mapping the EMU Shared Drive

!!! abstract "What this page tells you"
    Once your access ticket is complete, map the EMU drive in the remote desktop: File Explorer, right-click This PC, Map network drive, enter \\isilon-neurology\EMUReports. If it fails, retry with different credentials using your UPHS login.

Once your ticket has been marked as complete, you should have access to the drive. To map the drive to your remote desktop.


1. Log into the remote desktop and open **File Explorer**
2. Right Click on "**This PC**"
3. Click on "**Map network Drive**"
4. Use any free drive, and enter the filepath of the drive
**EMU Drive for Implant Powerpoints:** \\\\isilon-neurology\\EMUReports

1. If this doesn't work, repeat steps 2-4, and check off "**connect using different credentials**" and try logging in with your UPHS credentials
