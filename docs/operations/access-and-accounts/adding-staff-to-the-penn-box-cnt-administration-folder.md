# Adding Staff to the Penn+Box CNT Administration Folder

!!! abstract "What this page tells you"
    Add research staff to the Penn+Box CNT Administration folder by sharing it with their pennkey@upenn.edu address.

### Add to Penn+Box CNT Administration folder (for staff)

1. Go to [https://upenn.account.box.com/login](https://upenn.account.box.com/login)
2. Go to "CNT Administration" folder
3. Click Share and input Penn-affiliated email address ([pennkey@upenn.edu](mailto:pennkey@upenn.edu); the SEAS in @seas.upenn.edu is not needed)
