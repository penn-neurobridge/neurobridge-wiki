# 9. Leaving the lab

*Draft — mirror of section 3, in reverse.*

## Before your last week

- [ ] **Hand-off document** — for each pipeline or dataset you own: current state, where it lives, what is half-done, who takes it over.
- [ ] Every SOP you changed is updated and its *last verified* date set.
- [ ] Hand over data to the agreed project storage and code to the project repository so nothing lives only on your machine. Identifiable data may be held on approved PMACS systems, including cnt1, cnt-fs and BSC. Use Borel and external sharing destinations only for data permitted there; keep identifiable data out of code repositories. See [7. Regulatory and privacy essentials](regulatory-and-privacy.md).

## Access removal

The data manager works the removal column of the [Onboarding & Offboarding Checklist](cnt:operations/onboarding-and-offboarding/onboarding-and-offboarding-checklist.md): IRB protocols, PMACS and SEAS accounts, cnt1/cnt-fs, REDCap projects, [ieeg.org](http://ieeg.org) and Pennsieve projects, Box folders, AWS, GitHub, listservs, PennChart. Leftover user data on servers is organized and documented before removal.
