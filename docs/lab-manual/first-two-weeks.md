# 3. Your first two weeks

Work down this list in order — each item unlocks the next. Every link goes to the request procedure in Operations › Access & Accounts. Tick items off on your own copy of this page.

## Before day one (HR and the data manager start these)

- [ ] PennKey issued and Duo set up
- [ ] Added to the lab listservs (CNTlab, CNTworkgroup)
- [ ] Computer and peripherals ordered
- [ ] Added to the [Onboarding & Offboarding Checklist](../operations/onboarding-and-offboarding/onboarding-and-offboarding-checklist.md) — the master list of every account, who owns each step, and what is removed when you leave

## Week 1 — identity, training, network

- [ ] Read [CNT Data & Computing Orientation](../operations/onboarding-and-offboarding/cnt-data-and-computing-orientation.md)
- [ ] CITI human-subjects and HIPAA training complete; certificates to the regulatory coordinator
- [ ] [PennChart Training](../operations/onboarding-and-offboarding/pennchart-training.md) and [One HUP Pavilion Training](../operations/onboarding-and-offboarding/one-hup-pavilion-training.md) if you will enter the hospital
- [ ] Added to the IRB protocols you will work under — [Adding Personnel to an IRB Study](../operations/regulatory-irb-and-reporting/adding-personnel-to-an-irb-study.md) (or [Adding a Non-Penn / New Hire to a Study](../operations/regulatory-irb-and-reporting/adding-a-non-penn-new-hire-to-a-study.md))
- [ ] PMACS account requested; [PMACS VPN](../compute/pmacs-psom-systems/pmacs-vpn.md) installed
- [ ] [UPHS F5 VPN Access](../operations/access-and-accounts/uphs-f5-vpn-access.md) and [Citrix Remote Desktop Access](../operations/access-and-accounts/citrix-remote-desktop-access.md) requested (these take days — start early)
- [ ] Slack, the lab's project workspace and this wiki's GitHub repository — ask the PI

## Week 2 — servers, data systems, tools

- [ ] cnt1 and cnt-fs access confirmed — **Access CNT1 and CNT-fs** *(not yet in the wiki)*, then [VDI, cnt-fs and cnt1](../compute/overview/vdi-cnt-fs-and-cnt1.md)
- [ ] SEAS servers — [Accessing Borel over SSH](../compute/seas-cets-servers/accessing-borel-over-ssh.md), [Mounting Leif over SMB](../compute/seas-cets-servers/mounting-leif-over-smb.md)
- [ ] [Requesting a REDCap Account](../operations/access-and-accounts/requesting-a-redcap-account.md)
- [ ] [Adding Users to the ieeg.org Portal](../operations/access-and-accounts/adding-users-to-the-ieeg-org-portal.md) — ask an existing user to add you
- [ ] Pennsieve workspace access — [Pennsieve Data Access Rules](../data/sharing-pennsieve-and-ieeg-org/pennsieve-data-access-rules.md)
- [ ] [Adding Staff to the Penn+Box CNT Administration Folder](../operations/access-and-accounts/adding-staff-to-the-penn-box-cnt-administration-folder.md)
- [ ] GitHub: added to the penn-cnt organization — [Git on the VDI & UPHS Computers](../compute/software-and-tools/git-on-the-vdi-and-uphs-computers.md)
- [ ] Read [Data Storage Locations](../data/storage-locations/data-storage-locations.md) and **Data Structure v1.0 (Data › Sites)** *(not yet in the wiki)* — the two pages that define your job

## If you will cover clinical workflows

- [ ] [CRC Access Checklist (systems, badges, trainings)](../operations/access-and-accounts/crc-access-checklist-systems-badges-trainings.md) — badges, EMU drive, CAMRIS, Greenphire
- [ ] [7T Badge Access & MRI Safety Training](../imaging/at-the-scanner/7t-badge-access-and-mri-safety-training.md)
- [ ] Read [Consent Signing Checklist](../operations/consenting/consent-signing-checklist.md) before your first consent

- [ ] The PI — goals for your first six months (section 2)
- [ ] The data manager — who owns most of the access steps above
- [ ] The regulatory coordinator — IRB protocols and the e-regulatory binder
- [ ] Everyone on [Important Contacts & Emergency Numbers](../operations/contacts/important-contacts-and-emergency-numbers.md)
