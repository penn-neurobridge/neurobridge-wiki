# 3. Getting set up: accounts and access

Work down this list in order; each item unlocks the next. Every link goes to the request procedure. Most people finish it in two weeks; the hospital accounts take the longest, so request those first. Students and postdocs working only with de-identified data stop after the SEAS servers and GitHub.

## Before day one (HR and the data manager start these)

- [ ] PennKey issued and Duo set up
- [ ] Added to the lab listservs (CNTlab, CNTworkgroup)
- [ ] Computer and peripherals ordered
- [ ] Added to the [Onboarding & Offboarding Checklist](cnt:operations/onboarding-and-offboarding/onboarding-and-offboarding-checklist.md) — the master list of every account, who owns each step, and what is removed when you leave

## Week 1 — identity, training, network

- [ ] Read [CNT Data & Computing Orientation](cnt:operations/onboarding-and-offboarding/cnt-data-and-computing-orientation.md)
- [ ] CITI human-subjects and HIPAA training complete; certificates to the regulatory coordinator
- [ ] [PennChart Training](cnt:operations/onboarding-and-offboarding/pennchart-training.md) and [One HUP Pavilion Training](cnt:operations/onboarding-and-offboarding/one-hup-pavilion-training.md) if you will enter the hospital
- [ ] Added to the IRB protocols you will work under — [Adding Personnel to an IRB Study](cnt:operations/regulatory-irb-and-reporting/adding-personnel-to-an-irb-study.md) (or [Adding a Non-Penn / New Hire to a Study](cnt:operations/regulatory-irb-and-reporting/adding-a-non-penn-new-hire-to-a-study.md))
- [ ] PMACS account requested; [PMACS VPN](cnt:compute/pmacs-psom-systems/pmacs-vpn.md) installed
- [ ] [UPHS F5 VPN Access](cnt:operations/access-and-accounts/uphs-f5-vpn-access.md) and [Citrix Remote Desktop Access](cnt:operations/access-and-accounts/citrix-remote-desktop-access.md) requested (these take days — start early)
- [ ] Slack, the lab's project workspace and this wiki's GitHub repository — ask the PI

## Week 2 — servers, data systems, tools

- [ ] cnt1 and cnt-fs access confirmed (the data research coordinator requests it; the procedure page is still to be written), then [VDI, cnt-fs and cnt1](cnt:compute/overview/vdi-cnt-fs-and-cnt1.md)
- [ ] SEAS servers — [Accessing Borel over SSH](cnt:compute/seas-cets-servers/accessing-borel-over-ssh.md), [Mounting Leif over SMB](cnt:compute/seas-cets-servers/mounting-leif-over-smb.md)
- [ ] [Requesting a REDCap Account](cnt:operations/access-and-accounts/requesting-a-redcap-account.md)
- [ ] [Adding Users to the ieeg.org Portal](cnt:operations/access-and-accounts/adding-users-to-the-ieeg-org-portal.md) — ask an existing user to add you
- [ ] Pennsieve workspace access — [Pennsieve Data Access Rules](cnt:data/sharing-pennsieve-and-ieeg-org/pennsieve-data-access-rules.md)
- [ ] [Adding Staff to the Penn+Box CNT Administration Folder](cnt:operations/access-and-accounts/adding-staff-to-the-penn-box-cnt-administration-folder.md)
- [ ] GitHub: added to the penn-cnt organization — [Git on the VDI & UPHS Computers](cnt:compute/software-and-tools/git-on-the-vdi-and-uphs-computers.md)
- [ ] Read [Data Storage Locations](cnt:data/storage-locations/data-storage-locations.md) and the Data Structure v1.0 specification (ask the data research coordinator for it until it is on the wiki); the two documents that define your job

## If you will cover clinical workflows

- [ ] [CRC Access Checklist (systems, badges, trainings)](cnt:operations/access-and-accounts/crc-access-checklist-systems-badges-trainings.md) — badges, EMU drive, CAMRIS, Greenphire
- [ ] [7T Badge Access & MRI Safety Training](cnt:imaging/at-the-scanner/7t-badge-access-and-mri-safety-training.md)
- [ ] Read [Consent Signing Checklist](cnt:operations/consenting/consent-signing-checklist.md) before your first consent

## Meet

- [ ] The PI, about goals for your first six months ([Roles in the lab](roles-in-the-lab.md))
- [ ] The data manager — who owns most of the access steps above
- [ ] The regulatory coordinator — IRB protocols and the e-regulatory binder
- [ ] Everyone on [Important Contacts & Emergency Numbers](cnt:operations/contacts/important-contacts-and-emergency-numbers.md)
