# 0. Start here: the one-page map

!!! info
    **If you remember one thing:** every procedure lives in this wiki under one of six themes (the tabs above). Project decisions, meeting notes and people pages live in the lab's project workspace (ask the PI for access). Records with patient identifiers live in the CRC scheduling trackers and REDCap. If you don't know where to look, start here, or open the [map](../map/index.md).

## The six themes

| Theme | The question it answers | Go there for |
|---|---|---|
| [Data](../data/index.md) | Where is the data and how is it laid out? | Site inventory, BIDS layout, storage locations, moving data, Azure archive, Pennsieve, de-identification |
| [Compute](../compute/index.md) | What do I run this on, and how do I get in? | Borel, Leif, Finkel/SLURM, cnt1, cnt-fs, BSC, cntgpu1, AWS, Git, Linux, tickets |
| [Imaging](../imaging/index.md) | How does a scan get acquired and processed? | Booking 3T/7T/fMRI, scanner day, Flywheel/Pedro transfer, electrode reconstruction, RADAR |
| [Electrophysiology](../electrophysiology/index.md) | How does a recording get acquired and processed? | EMU tasks, Natus export, channel mapping, natus2mef → [ieeg.org](http://ieeg.org), scalp EEG, Mxene |
| [REDCap & Clinical Metadata](../redcap/index.md) | Where do clinical variables live and how are they entered? | REDCap projects, data entry, EPIC/RADAR → REDCap pulls |
| [Operations](../operations/index.md) | How do I get set up, and how does a study run? | Every access request, onboarding, IRB, consent, scheduling, Greenphire, neuropsych testing, contacts |

## Three rules that make it predictable

1. **Every account or access request is in Operations › Access & Accounts** — one checklist, whatever system it unlocks.
2. **Nothing with patient identifiers or a password is in this wiki.** Trackers stay in the PHI-approved tracker and REDCap; credentials live in the password manager.
3. **If it is a procedure, it goes in a theme. If it is a project decision, it goes in Projects.** Meeting notes go in Lab Meetings.
    - **Code** — the penn-cnt GitHub organization.
