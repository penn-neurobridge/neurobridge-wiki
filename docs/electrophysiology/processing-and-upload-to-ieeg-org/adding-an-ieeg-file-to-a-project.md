# Adding an iEEG File to a Project

!!! abstract "What this page tells you"
    If an uploaded ieeg.org dataset did not land in the right project, open the dataset by ID to confirm the upload, then open the project and check off the file to add it.

*   if an [ieeg.org](http://ieeg.org) file does not add to the correct project after uploading to [ieeg.org](http://ieeg.org), follow the steps below

1. open the [ieeg.org](http://ieeg.org) dataset: open dataset by ID
2. it will open and confirm it is correctly uploaded
3. open the [ieeg.org](http://ieeg.org) project
4. check off the file you want to add
5. TADA!
